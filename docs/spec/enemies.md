# 敵キャラクター素材

## 保存場所・命名規則

実際にアプリで使う画像は [public/enemies/](../../public/enemies/) に置く。

ファイル名: `e{敵ID2桁}_{種類}{連番2桁}.png`（`e`はenemyのe）。`d01`〜`d03`のルールは[characters.md](./characters.md)の仲間キャラと同じ（`d01`=通常、`d02`=攻撃、`d03`=ダメージ）。仲間キャラと異なり、敵は立ち絵（`t01`）は無く、戦闘用ドット絵の3枚セットのみ。

現在 `e01`〜`e06` の6体分（計18枚）が揃っている。

| ID | 見た目 |
| --- | --- |
| e01 | ゴブリン（棍棒を持った緑色の小鬼） |
| e02 | オーク（ゴブリンより大柄・防具付き） |
| e03 | 呪われたテディベア |
| e04 | きのこの魔物 |
| e05 | 氷のスライム |
| e06 | 緑のスライム |

各敵の正式名称・ステータス・出現する背景（[fields.md](./fields.md)）との対応は未定（今後決める）。

## 運用ルール・画像の加工

[characters.md](./characters.md)と同じ運用。画像は `WebApp_game/サンプル画像/` フォルダにユーザー側が置き、`public/enemies/` に**コピー**して使う（`サンプル画像/` の中身は消さない・移動しない）。

戦闘用ドット絵は白背景が焼き込まれているため、**外周から連結している画素だけを透過するフラッドフィル方式**（[characters.md](./characters.md)の「画像の加工」参照）で透過処理してから配置している。処理後はマゼンタで穴を可視化した診断画像で全6体を目視確認済み（穴なし）。
