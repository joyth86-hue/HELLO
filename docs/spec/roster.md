実装（実データ）: [lib/characters-info.ts](../../lib/characters-info.ts)（仲間）、[lib/enemies-info.ts](../../lib/enemies-info.ts)（敵）

## 属性（現時点で登場しているもの）

呼び名・種類の正式な一覧は未定だが、現時点で実際に使われているのは以下の5種類。

- 炎（c01）
- 草（c02, c04, e01, e02, e04, e06）

- 水（e05）

## 属性の相性（弱点・耐性）

ユーザー確認済み。5属性を輪状につなぎ、矢印の先が弱点（＝攻撃側が有利）を表す。

**水 → 炎 → 氷 → 草 → 岩 → 水**

- 輪の中で**直接つながっている**（隣り合う）属性を攻撃した場合：ダメージ**×1.25**
- 逆方向（矢印の先の属性が、根元の属性を攻撃した場合）：ダメージ**×0.75**
- それ以外の組み合わせ（輪で2つ離れている・同じ属性同士）：等倍**×1.0**（輪に2段階以上先の間接的な有利・不利は考慮しない、ユーザー確認済み）
- 実装：[lib/combat.ts](../../lib/combat.ts)の`getElementMultiplier()`。通常攻撃は属性を持たない（[skills.md](./skills.md)参照）ため、この倍率は常に1.0固定のまま
- 敵は通常攻撃相当の行動のみでスキル・属性を持たないため、現状この倍率が実際に効くのは「プレイヤーのスキル攻撃 → 敵」の向きのみ（敵の属性は保持している値をそのまま使う）

### ブローチ（属性耐性）による軽減

ユーザー確認済み。ブローチ（アーティファクト、[items.md](./items.md#装備によるステータス加算)参照）の属性耐性ptは、**自分が弱点を突かれた（1.25倍を受ける）場合にのみ**、その倍率を直接軽減する。有利（0.75倍）・無関係（1.0倍）のケースには影響しない。

```
弱点を突かれた場合の実際の倍率 = max(0.75, 1.25 − 属性耐性pt × 0.5%)
```

- 1pt＝0.5%減（会心率などの「1pt＝1%」の半分の効き）。床は0.75倍——耐性を積み切ると、弱点だった相手にも有利な側と同じ倍率まで持っていける
- 底（0.75倍）に到達するには合計100pt必要。SSブローチ（基礎16pt）を3枠とも合成なしで装備しても48ptなので、**3枠すべてを+22前後まで合成して初めて到達する**、しっかり投資が必要な水準にしてある（ユーザー確認済み：装備を揃えただけで頭打ちにならないように、1pt＝1%ではなく0.5%にして合成の伸びしろを残した）
- 実装：[lib/combat.ts](../../lib/combat.ts)の`getElementMultiplier()`第3引数（`defenderResistPoints`）、[app/games/game1/battle/page.tsx](../../app/games/game1/battle/page.tsx)の`BattleUnit.elementResistPoints`

**現状の注意点**：敵は常に属性なしの通常攻撃しか行わない（上記）ため、「敵の攻撃で弱点を突かれる」という状況自体が今のところ発生しない。つまりブローチの属性耐性・[skills.md](./skills.md)の支援スキル「舐められたものね」による属性耐性バフは、**計算式としては実装済みだが、敵が属性攻撃を持たない限りゲームプレイ上は効果が発生しない**（今後、属性を持つ敵スキルが追加された場合に効いてくる想定）。
