# ビジュアルデザイン方針

現時点では仮のデザイン。今後、実際のゲームコンテンツに合わせて見直す前提。

## 配色・ボタン方向

初期は「やさしいパステル」（淡いミント背景）で開始したが、「あきくんゲームズ」時代の名残で世界観に合っていなかったため、**ダーク系＋流れる背景模様**に変更した（下記「背景（流れる文字パターン）」参照）。ボタンなどの「ステッカー風」デザイン自体は変えず、背景がダークになったことで色味だけ調整している。

- 背景：ダーク系グラデーション `#14132a` 〜 `#1c1a3a`（`--background`、[app/globals.css](../../app/globals.css)。Tailwindのユーティリティクラスとしては `bg-background`）＋[流れる文字パターン](#背景流れる文字パターン)
- 基本の文字色：明るいオフホワイト（`#f4f1ff` 相当、`--foreground`）
- ボタン（有効・押せるもの）：白地＋黒の太め（2px）縁取り＋オフセット影（ぼかし無し、右下にずらしただけの「ステッカー風」）は据え置き。影の色だけ、黒背景で沈んで見えなくなるため紫系 `#4a3f86` に変更。押すとボタン自体が影の位置まで沈み込み、影が小さくなることで「物理的に押した」感触を出す。実装：[lib/ui.ts](../../lib/ui.ts) の `stickerButton`
- ボタン（無効・押せないもの、例：メニューのComing soon）：薄いグレー背景＋グレー文字、影や縁取りなし（`stickerButtonDisabled` または個別のグレー系クラス）
- カード類（ステータスカード、アイテムカードなど）：半透明の白（`rgba(255,255,255,0.06〜0.09)`）＋薄い紫の縁取り（`rgba(201,195,255,0.35〜0.55)`）のガラス風。キャラクター確認画面の額縁やバッグ画面の詳細シートのようにクリーム色 `#fffaf0` の紙・額縁を模したパーツは、ダーク背景に映えるためそのまま維持

OS・ブラウザのダークモード設定に関わらず、常にこの配色（固定）で表示する。ゲームとしてのブランド・見た目を統一するため。

パステルミント案を含む比較検討した他の案は不採用。

## 背景（流れる文字パターン）

ホーム画面・キャラクター確認画面・バッグの中身画面の3画面で、「hiro games」の文字が右上から左下へ斜めに流れ続ける背景を使っている。実装は[components/GameBackground.tsx](../../components/GameBackground.tsx)を各画面のルート要素の最初の子として置く形（詳細はコンポーネント内のコメント参照）。

- ダークグラデーションのベース層（インラインスタイルのCSSグラデーション）
- 「hiro games」の文字を敷き詰めた模様の層：[public/backgrounds/pattern-hiro-games.svg](../../public/backgrounds/pattern-hiro-games.svg)（210×85pxのシームレスタイル、22度傾けた文字を段ごとに150pxずらして配置）を`background-repeat`で敷き詰め、`animate-bg-drift`（[app/globals.css](../../app/globals.css)）で1周7秒のループアニメーションをかけている
- **文字の傾きと流れる向きは同じ角度に揃えている**（ユーザー指摘により調整済み。ズレていると違和感が出る）
- 内側に軽いビネット（`shadow-[inset_...]`）をかけて中央を見やすくしている
- `prefers-reduced-motion: reduce`が有効な環境ではアニメーションを止める

検討時にArtifactで作ったモックアップ：[背景デザイン案](https://claude.ai/code/artifact/214e7109-c50f-435e-a94e-a361cc4af896)（ホーム画面・バッグ画面のイメージ、傾き・ずらし幅・速度の調整もここで実施）。

ホーム画面のみ、この模様とは別に専用の背景イラストを使っている（詳細は[screens/game1-home.md](./screens/game1-home.md)参照）。

## フォント・見た目のトーン

- 手書き感のあるロゴと、ステッカーのような立体感のあるボタンで、シンプルながら少し遊び心のあるトーンにする
- 角丸のボタン・カードを使用し、硬すぎない印象にする

## ロゴ（「あきくんゲームズ」ブランド・現在未使用）

複数ゲームをまとめるハブ画面があった頃に、そのブランド名「あきくんゲームズ」用に作成したロゴ。ハブ画面自体を廃止した（[screens/start.md](./screens/start.md)参照）ため、現在はどこにも表示されていないが、実装は残してある。

- ロゴタイプ：「まる文字ポップ」案で確定（Google Fonts の `Hachi Maru Pop`）。手書きの丸っこいポップな文字。
- 実装：[components/Logo.tsx](../../components/Logo.tsx)。文字ごとに角度・縦位置を少しずつ決まった計算式でずらし、手書きの「がたがた」感を出している（乱数ではないのでサーバー・クライアントで見た目が一致する）。
- フォント自体は `app/layout.tsx` の `<head>` で Google Fonts の `<link>` から読み込んでいる（`next/font/google` は日本語文字を含むフォントの扱いが不安定なため見送り）。
- 検討時に他4案（ゆるふわ／マーカー太字／筆ペン／ラフスケッチ二重線）も作成したが、今回は不採用。
- `animate-fade-up`（[app/globals.css](../../app/globals.css)）というフェード＋浮き上がりの演出クラスも、このロゴ表示のために作ったもので、同様に現在未使用。

## 今後

各ゲームのジャンルに応じて、ゲーム内画面はここで定めた全体トーンから外れた独自の配色を使う可能性がある。その場合はこのファイルに「共通UI（スタート・メニュー）の配色」と「ゲーム個別の配色」を分けて追記する。
