# ビジュアルデザイン方針

現時点では仮のデザイン。今後、実際のゲームコンテンツに合わせて見直す前提。

## 配色

- 背景：白
- 基本の文字色：黒（濃いグレー `#171717` 相当）
- ボタン（有効・押せるもの）：黒背景＋白文字（コントラストを出す）
- ボタン（無効・押せないもの、例：メニューのComing soon）：薄いグレー背景＋グレー文字
- 通貨表示バッジ：黒背景＋白文字の丸ピル

OS・ブラウザのダークモード設定に関わらず、常にこの配色（ライト固定）で表示する。ゲームとしてのブランド・見た目を統一するため。

## フォント・見た目のトーン

- モダン・シンプルを基調とし、装飾は最小限
- 角丸のボタン・カードを使用し、硬すぎない印象にする

## ロゴ

- ロゴタイプ：「まる文字ポップ」案で確定（Google Fonts の `Hachi Maru Pop`）。手書きの丸っこいポップな文字。
- 実装：[components/Logo.tsx](../../components/Logo.tsx)。文字ごとに角度・縦位置を少しずつ決まった計算式でずらし、手書きの「がたがた」感を出している（乱数ではないのでサーバー・クライアントで見た目が一致する）。
- フォント自体は `app/layout.tsx` の `<head>` で Google Fonts の `<link>` から読み込んでいる（`next/font/google` は日本語文字を含むフォントの扱いが不安定なため見送り）。
- 検討時に他4案（ゆるふわ／マーカー太字／筆ペン／ラフスケッチ二重線）も作成したが、今回は不採用。

## トップ画面の演出

- スタート画面を開いたとき、中央のロゴが**フェード＋少し下から浮き上がる**演出で表示される（`animate-fade-up`、[app/globals.css](../../app/globals.css)）。
- `prefers-reduced-motion` が有効な環境ではアニメーションを無効化する。

## 全体の配色・ボタン形状（検討中）

現在の白黒グレー基調に加えて、背景・配色・ボタン形状をセットにした4方向を比較検討中（スタート画面をベースにしたモックアップ）。

1. ペーパー×モノトーン：現状に近い白黒基調＋うっすら紙のドット質感
2. マーカーアクセント：白背景＋オレンジのマーカー色をボタン・下線に一点投入
3. やさしいパステル：淡いミント背景＋黒縁のステッカー風ボタン
4. スケッチ帳：クリーム色のドット方眼紙背景＋手描き風の歪んだ枠のボタン

いずれかに決まり次第、この節を確定版の配色ルールに置き換え、メニュー画面・各ゲーム画面にも同じ方向を適用していく。

## 今後

各ゲームのジャンルに応じて、ゲーム内画面はここで定めた全体トーンから外れた独自の配色を使う可能性がある。その場合はこのファイルに「共通UI（スタート・メニュー）の配色」と「ゲーム個別の配色」を分けて追記する。
