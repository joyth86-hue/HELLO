# ビジュアルデザイン方針

現時点では仮のデザイン。今後、実際のゲームコンテンツに合わせて見直す前提。

## 配色

- 背景：白
- 基本の文字色：黒（濃いグレー `#171717` 相当）
- ボタン（有効・押せるもの）：黒背景＋白文字（コントラストを出す）
- ボタン（無効・押せないもの、例：メニューのComing soon）：薄いグレー背景＋グレー文字
- 通貨表示バッジ：黒背景＋白文字の丸ピル

OS・ブラウザのダークモード設定に関わらず、常にこの配色（ライト固定）で表示する。ゲームとしてのブランド・見た目を統一するため。

## フォント・見た目のトーン

- モダン・シンプルを基調とし、装飾は最小限
- 角丸のボタン・カードを使用し、硬すぎない印象にする

## 今後

各ゲームのジャンルに応じて、ゲーム内画面はここで定めた全体トーン（白・黒・グレー基調）から外れた独自の配色を使う可能性がある。その場合はこのファイルに「共通UI（スタート・メニュー）の配色」と「ゲーム個別の配色」を分けて追記する。
