# アイテム素材

## 保存場所・命名規則

実際にアプリで使う画像は [public/items/](../../public/items/) に置く。

ファイル名: `i{連番3桁}.png`（`i`はitemのi）。実データは [lib/items-info.ts](../../lib/items-info.ts) を参照。

現在 `i001`〜`i250` の250個分が揃っている。内訳は以下の4種類（`type`）。

| type | 対応する武器種 | 個数 | ID範囲 |
| --- | --- | --- | --- |
| 片手剣 | 仲間の武器種「片手剣」用（アカネ） | 25 | i001〜i025 |
| 法器 | 仲間の武器種「法器」用（カエデ・コユキ） | 25 | i026〜i050 |
| 弓 | 仲間の武器種「弓」用（サユミ） | 25 | i051〜i075 |
| アーティファクト | 武器種を問わない装飾品 | 175 | i076〜i250 |

武器種の対応は[roster.md](./roster.md)の仲間キャラクター一覧（`weaponType`）を参照。

### アーティファクトの内訳（`slot`）

アーティファクト175個は、装備部位ごとに7種類×各25個（レアリティ5種×5個）に分かれている。

| slot | 個数 | ID範囲 |
| --- | --- | --- |
| 護符 | 25 | i076〜i100 |
| 指輪 | 25 | i101〜i125 |
| 腕輪 | 25 | i126〜i150 |
| 首飾り | 25 | i151〜i175 |
| 耳飾り | 25 | i176〜i200 |
| ブローチ | 25 | i201〜i225 |
| 帯留め | 25 | i226〜i250 |

### レアリティ

`C` / `B` / `A` / `S` / `SS` の5段階。武器種・アーティファクトのslotごとに、各レアリティ5個ずつ揃っている（レアリティが上がるほど強い、という前提だが数値バランスは未定）。

## 元データ・画像の作り方

アイテム画像は`WebApp_game`とは別の場所（`C:\Users\田中宏樹\Documents\Codex\hirogames_images\assets\items\catalog_v1`）でユーザー側が用意したもの。この元フォルダも[characters.md](./characters.md)の`サンプル画像/`と同様、**中身を消したり移動したりせず、`public/items/`へコピーして使う**。

元画像は1254×1254px・1枚あたり約1.2〜1.5MBで、レアリティごとの背景色・枠・レアリティ文字が画像に焼き込まれた正方形アイコン（透過なし）。250枚をそのままのサイズでコピーすると容量が大きくなりすぎるため（合計300MB超）、`sharp`でニアレストネイバー法（`kernel: "nearest"`）を使い256×256pxへ縮小してから`public/items/`に配置している。ドット絵特有の輪郭のカクカクした感じを保ったまま、合計約29MBまで縮小できることを確認済み。

## データ構造（基本情報）

[lib/items-info.ts](../../lib/items-info.ts)の`ItemBaseInfo`が、アイテム1個につき一意に定まる基本情報（ID・名称・説明文・種類・レアリティ・画像パス、アーティファクトのみslot）を持つ。仲間・敵キャラクターと同様、**攻撃力や効果などのゲーム的なパラメータ（成長テーブルに相当するもの）はまだ未定で、あえてこのファイルには含めていない**。

## 画面での利用

所持しているアイテムを一覧表示する[バッグの中身画面](./screens/bag.md)（`/games/game1/bag`）で使用している。所持数の管理方法は[save-data.md](./save-data.md)の`Game1SaveData.inventory`を参照。

## 今後（未定・空欄のパラメータ）
