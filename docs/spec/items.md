## 保存場所・命名規則

実際にアプリで使う画像は [public/items/](../../public/items/) に置く。

ファイル名: `i{連番3桁}.png`（`i`はitemのi）。実データは [lib/items-info.ts](../../lib/items-info.ts) を参照。

現在 `i001`〜`i250` の250個分が揃っている。内訳は以下の4種類（`type`）。

| type | 対応する武器種 | 個数 | ID範囲 |
| --- | --- | --- | --- |
| 片手剣 | 仲間の武器種「片手剣」用（アカネ） | 25 | i001〜i025 |

武器種の対応は[roster.md](./roster.md)の仲間キャラクター一覧（`weaponType`）を参照。

## 装備によるステータス加算

実装: [lib/item-effects.ts](../../lib/item-effects.ts)。装備1個につき、種類（武器種／アーティファクトのslot）ごとに決まった1つのステータスへ効果を発揮する。

| 装備 | 効果ステータス |
| --- | --- |
| 武器（片手剣／法器／弓） | 攻撃力（**固定値**加算） |
| 護符 | HP（％加算） |
| 指輪 | 攻撃力（％加算） |
| 腕輪 | 防御力（％加算） |
| 首飾り | 会心率（ptを直接加算） |
| 耳飾り | 会心ダメージ（ptを直接加算） |
| ブローチ | 属性耐性（ptを直接加算。属性システム自体が未実装のため、当面は数値の表示のみで戦闘には影響しない） |
| 帯留め | HP／攻撃力／防御力の3つに、それぞれ半分の割合で少しずつ（％加算） |

**武器だけ「攻撃力への固定値加算」、それ以外（アーティファクト）は「％加算」**（ゲームデザイン上の好みとして、武器はレベルアップとは別に足し算で分かりやすく伸ばしたい、という方針。ユーザー確認済み）。

上昇量はレアリティ別（ユーザー確認済みの仮数値、後から係数を書き換えて調整可能）。

- 武器の固定値：C+30 / B+60 / A+110 / S+180 / SS+300（キャラのレベルアップ1回あたりの伸び幅、例えばアカネなら攻撃力+6.0/レベルと比べて、装備を替えたことがはっきり実感できる大きさを狙っている）
- HP・攻撃力・防御力に効くアーティファクト：そのステータスの基礎値（レベルなりの値）に対する割合加算。C+3% / B+6% / A+10% / S+16% / SS+25%（帯留めはこの半分をHP/攻撃力/防御力それぞれに）
- 会心率・会心ダメージ・属性耐性に効く装備：%ポイントを直接加算。C+2pt / B+4pt / A+7pt / S+11pt / SS+16pt

武器1つ＋アーティファクト3枠、装備している分すべてを合算する（[character-view.md](./screens/character-view.md)の装備欄・[lib/game1-data.ts](../../lib/game1-data.ts)の`CharacterEquipment`参照）。キャラクター画面のSTATUS表示・戦闘（[battle-test.md](./screens/battle-test.md)）の両方に反映される。

**装備は所持数分しか使えない**（前提事項、調整対象ではない）。同じ個体（インスタンス）を複数キャラクターへ同時装備することはできない。武器・アーティファクトを問わず、キャラクター全員の装備欄（武器1枠＋アーティファクト3枠×人数）に使われている個体は、他のスロットの候補一覧から除外される（[lib/game1-data.ts](../../lib/game1-data.ts)の`isInstanceEquippedElsewhere()`）。1つしか持っていないアイテムは1人にしか装備できないため、パーティ全員を同じ強さの装備で揃えるには複数個ドロップさせる（または合成で個体を増やすのではなく強化する）必要がある。

## アイテムの個体管理（合成のための前提）

アイテムは「ID＋所持数」ではなく、**1個1個が固有の個体（インスタンス）**として管理される（[lib/game1-data.ts](../../lib/game1-data.ts)の`ItemInstance`：`instanceId`・`itemId`・`plus`）。同じ`itemId`のアイテムでも、下記の合成によって個体ごとに強化度合い（`plus`）が異なりうるため。装備欄（`CharacterEquipment`）が参照する値も、アイテムIDではなく個体ID。

所持数の上限は**100個体**（[lib/game1-data.ts](../../lib/game1-data.ts)の`INVENTORY_CAP`）。上限に達している状態でアイテムがドロップした場合は受け取れない（「受け取れませんでした」とだけ表示し、**何のアイテムだったかは表示しない**——レアなアイテムだった場合に悔しい思いをさせないための仕様）。

## アイテムの合成（強化）

実装: [lib/item-synthesis.ts](../../lib/item-synthesis.ts)。ユーザー確認済みのルール：

- 対象：**同じ武器種同士**（片手剣／法器／弓、種類が同じならレア度・見た目違いでもOK）、または**同じアーティファクトslot同士**（護符同士、指輪同士…）のみ。武器種を跨いだり、slotが違うアーティファクト同士は合成できない
- 一括合成対応：残す方（対象）を1つ選び、素材を複数まとめて選んで1回で合成する
- 合成後に残る個体は、関わった中で**一番レア度が高いもの**（見た目・アイテムIDはそのまま）。**同レア度どうしの場合は、プレイヤーが「対象」として選んだ方**が残る（レア度と見た目・IDの対応関係自体は常に固定で、合成によって変わることはない）
- 素材1個につき、（その素材自身の`plus`値 + 1）に「レア度差の割引」を掛けた分だけ、残る個体の`plus`に加算する
  - レア度差の割引：1段差=1/2、2段差=1/4、3段差=1/8、4段差=1/16（2^段差で割る）。同レア度は割引なし（1倍）
  - 「+1」しているのは、真新しい（`plus`が0の）素材でも1回分の合成価値（後述の5%）は必ず持つようにするため
- `plus`は内部では端数（小数）まで正確に保持し、**実際の効果・表示には切り捨てた整数値**を使う。切り捨てた結果+0のままになる組み合わせ（例：低レアを大量に上位レアへ合成しようとした場合）もあるため、合成前にプレビュー（変化後の値）を必ず表示し、確認してから確定する
- 効果量は`plus`1につき、**そのアイテム自身の元の基礎値の5%**増加（複利ではなく毎回同じ幅）。武器（固定値）ならその5%、アーティファクト（％／pt）ならその数値自体の5%
- 合成はキャラクター画面から行う。素材・対象にできるのは「未装備のアイテム」と「今表示中のキャラクター自身が装備しているアイテム」のみ。**他のキャラクターが装備中のアイテムは候補に出ない**（見えていないキャラクターの装備が知らないうちに消費されるのを防ぐため）。消費された個体がどこかに装備されていた場合は、装備欄から自動的に外れる

## アイテムごとの能力差（将来課題）

現状、効果値はアイテムの`type`（武器種など）と`rarity`（レア度）だけで決まり、**個別のアイテムID自体は効果に一切関与しない**。例えば片手剣のCランクは、木刀・石の剣・銅剣・ブロンズエッジ・鉄剣のどれを装備しても完全に同じ効果になる（見た目だけが違う）。同じ種類・同じレア度で5種類ずつ用意されている意味を持たせるには、最終的には個別のアイテムIDごとに能力差をつける必要がある。今回のスコープでは対応せず、別途まとめて対応する。
