# アイテム素材

## 保存場所・命名規則

実際にアプリで使う画像は [public/items/](../../public/items/) に置く。

ファイル名: `i{連番3桁}.png`（`i`はitemのi）。実データは [lib/items-info.ts](../../lib/items-info.ts) を参照。

現在 `i001`〜`i250` の250個分が揃っている。内訳は以下の4種類（`type`）。

| type | 対応する武器種 | 個数 | ID範囲 |
| --- | --- | --- | --- |
| 片手剣 | 仲間の武器種「片手剣」用（アカネ） | 25 | i001〜i025 |
| 法器 | 仲間の武器種「法器」用（カエデ・コユキ） | 25 | i026〜i050 |
| 弓 | 仲間の武器種「弓」用（サユミ） | 25 | i051〜i075 |
| アーティファクト | 武器種を問わない装飾品 | 175 | i076〜i250 |

武器種の対応は[roster.md](./roster.md)の仲間キャラクター一覧（`weaponType`）を参照。

### レアリティ

`C` / `B` / `A` / `S` / `SS` の5段階。武器種・アーティファクトのslotごとに、各レアリティ5個ずつ揃っている（レアリティが上がるほど強い、という前提だが数値バランスは未定）。

## 元データ・画像の作り方

アイテム画像は`WebApp_game`とは別の場所（`C:\Users\田中宏樹\Documents\Codex\hirogames_images\assets\items\catalog_v1`）でユーザー側が用意したもの。この元フォルダも[characters.md](./characters.md)の`サンプル画像/`と同様、**中身を消したり移動したりせず、`public/items/`へコピーして使う**。

元画像は1254×1254px・1枚あたり約1.2〜1.5MBで、レアリティごとの背景色・枠・レアリティ文字が画像に焼き込まれた正方形アイコン（透過なし）。250枚をそのままのサイズでコピーすると容量が大きくなりすぎるため（合計300MB超）、`sharp`でニアレストネイバー法（`kernel: "nearest"`）を使い256×256pxへ縮小してから`public/items/`に配置している。ドット絵特有の輪郭のカクカクした感じを保ったまま、合計約29MBまで縮小できることを確認済み。

## データ構造（基本情報）

[lib/items-info.ts](../../lib/items-info.ts)の`ItemBaseInfo`が、アイテム1個につき一意に定まる基本情報（ID・名称・説明文・種類・レアリティ・画像パス、アーティファクトのみslot）を持つ。

## 装備によるステータス加算

実装: [lib/item-effects.ts](../../lib/item-effects.ts)。装備1個につき、種類（武器種／アーティファクトのslot）ごとに決まった1つのステータスへ効果を発揮する。

| 装備 | 効果ステータス |
| --- | --- |
| 武器（片手剣／法器／弓） | 攻撃力 |
| 護符 | HP |
| 指輪 | 攻撃力 |
| 腕輪 | 防御力 |
| 首飾り | 会心率 |
| 耳飾り | 会心ダメージ |
| ブローチ | 属性耐性（属性システム自体が未実装のため、当面は数値の表示のみで戦闘には影響しない） |
| 帯留め | HP／攻撃力／防御力の3つに、それぞれ半分の割合で少しずつ |

上昇量はレアリティ別（ユーザー確認済みの仮数値、後から係数を書き換えて調整可能）。

- HP・攻撃力・防御力に効く装備：そのステータスの基礎値（レベルなりの値）に対する割合加算。C+3% / B+6% / A+10% / S+16% / SS+25%（帯留めはこの半分をHP/攻撃力/防御力それぞれに）
- 会心率・会心ダメージ・属性耐性に効く装備：%ポイントを直接加算。C+2pt / B+4pt / A+7pt / S+11pt / SS+16pt

武器1つ＋アーティファクト3枠、装備している分すべてを合算する（[character-view.md](./screens/character-view.md)の装備欄・[lib/game1-data.ts](../../lib/game1-data.ts)の`CharacterEquipment`参照）。キャラクター画面のSTATUS表示・戦闘（[battle-test.md](./screens/battle-test.md)）の両方に反映される。

**装備は所持数分しか使えない**（前提事項、調整対象ではない）。同じ個体を複数キャラクターへ同時装備することはできない。武器・アーティファクトを問わず、キャラクター全員の装備欄（武器1枠＋アーティファクト3枠×人数）に使われている合計数が、その所持数を超える選択は装備ピッカーの候補に出ない（[lib/game1-data.ts](../../lib/game1-data.ts)の`countEquippedInstances()`）。1つしか持っていないアイテムは1人にしか装備できないため、パーティ全員を同じ強さの装備で揃えるには複数個ドロップさせる必要がある。

## アイテムドロップ

実装: [lib/item-drop.ts](../../lib/item-drop.ts)。ドロップ確率・レアリティ抽選テーブルは[adventure-system.md](./adventure-system.md#アイテムドロップ)参照。レアリティが決まった後、どのアイテムになるかはそのレアリティの全アイテムから均等ランダム（武器種問わず）。

## 画面での利用

所持しているアイテムを一覧表示する[バッグの中身画面](./screens/bag.md)（`/games/game1/bag`）で使用している。所持数の管理方法は[save-data.md](./save-data.md)の`Game1SaveData.inventory`を参照。
