# 下部ナビゲーションバー

実装: [components/BottomNavBar.tsx](../../../components/BottomNavBar.tsx)、共有レイアウト: [app/games/game1/(main)/layout.tsx](<../../../app/games/game1/(main)/layout.tsx>)

## 概要

マップ／ショップ／冒険（ホーム）／仲間／バッグの5画面で共通して画面下部に表示する、常設のタブバー。今までの「ホーム画面から個別画面に行って✕で戻る」（ハブ＆スポーク）の構成から、**5つのメイン画面をこのバーで直接行き来する**構成に変更した。参考にしたのは他ゲームの、選択中のタブが丸く縁取られてせり出す動き。

## 画面構成との対応

Next.jsのルートグループ `app/games/game1/(main)/` の下に5画面を置き、共通レイアウト（`layout.tsx`）で`<BottomNavBar />`を1回だけ描画している（ルートグループ自体はURLに影響しない）。

| タブ | ラベル | 遷移先 | 画面の仕様書 |
| --- | --- | --- | --- |
| map | マップ | `/games/game1/map` | 未実装（プレースホルダーのみ） |
| shop | ショップ | `/games/game1/shop` | 未実装（プレースホルダーのみ） |
| adventure | 冒険 | `/games/game1/home` | [game1-home.md](./game1-home.md) |
| party | 仲間 | `/games/game1/character` | [character-view.md](./character-view.md) |
| bag | バッグ | `/games/game1/bag` | [bag.md](./bag.md) |

現在のURL（`usePathname()`）とタブの`href`を突き合わせて、選択中のタブを判定している。

## 見た目・アニメーション

- 黒地半透明のバー（`bg-black/85`）を画面下端に固定表示（`fixed`）
- タブは丸いアイコンボタン。非選択時は56px（`h-14 w-14`）、選択中は72px（約1.29倍）に一回り大きくなり、紫系の縁取り＋背景色付きで上にせり出す（`translate-y`とサイズをCSSトランジションで変化）
- **ラベル文字（マップ／ショップ／冒険／仲間／バッグ）は常時表示ではない。選択中のタブの円の中に、アイコンの下に小さく表示されるだけ**で、非選択のタブにはアイコンのみでラベルは出さない
- 選択されていない隣のタブは、せり出した分のスペースを空けるように少し詰まる（各タブを`flex`アイテムにして、選択中のものだけ`flex-grow`を大きくし、遷移をアニメーションさせている）

## アイコン画像

各タブの透過アイコン画像を[public/icons/nav/](../../../public/icons/nav/)に配置済み（元画像は512×512pxをニアレストネイバー法で128×128pxに縮小）。

| タブ | ファイル |
| --- | --- |
| マップ | `icon_map.png` |
| ショップ | `icon_shop.png` |
| 冒険 | `icon_battle.png`（剣のアイコン） |
| 仲間 | `icon_chara.png` |
| バッグ | `icon_bag.png` |

`components/BottomNavBar.tsx`の`NavTab.icon`に画像パスを指定する形。今後アイコンを差し替える場合は、この配列の該当パスを変更するだけでよい。

**`icon_chara.png`は最初に受け取ったものが実は透過されておらず、チェッカーボード模様がそのまま不透明画素として焼き込まれていた**（`sharp`で確認すると`hasAlpha: false`）。[characters.md](../characters.md)と同じ「外周から連結している画素だけ透過するフラッドフィル方式」で、チェッカーボードの2色（無彩色・中間輝度の画素）を背景とみなして除去し直した。他の4枚は元から正しく透過されていたため未加工。
