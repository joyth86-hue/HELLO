# ショップ（武器ガチャ）画面（`/games/game1/shop`）

実装: [app/games/game1/(main)/shop/page.tsx](<../../../app/games/game1/(main)/shop/page.tsx>)

## 概要

下部ナビゲーションバー（[bottom-nav.md](./bottom-nav.md)）の「ショップ」タブ＝武器ガチャ画面。宝箱をタップすると開封演出（レア度に応じたエフェクト差分）が再生され、最後にレア度だけを表示する。

**現状は演出確認版**で、以下は未実装（ユーザー確認済み：一旦UIの演出だけ確認したいとの意図で、これらは今回のスコープ外）。

- ガチャで実際にアイテムを付与する処理（`Game1SaveData.inventory`への追加は行わない）
- ポイント消費（現状は無制限に引ける）

## 演出素材

元データ：`C:\Users\田中宏樹\Documents\Codex\hirogames_images\assets\gacha\chest_reveal_v1\`（このアプリのリポジトリ外にある画像制作用フォルダ、`README.md`に仕様あり）。[characters.md](../characters.md)・[items.md](../items.md)と同様、元フォルダの中身は変更せず、使う分だけ`public/`へコピーして使う。

- コピー元：`frames/<rarity>/frame_00.png`〜`frame_08.png`（レア度ごとのVFXを合成済み、512×512px透過PNG、9フレーム）
- コピー先：[public/gacha/chest/\<rarity\>/frame_00.png](../../../public/gacha/chest/)〜`frame_08.png`（`rarity`は`C`/`B`/`A`/`S`/`SS`）
- `frames/base/`（VFX無しの共通宝箱9フレーム）はコピーしていない。各`frames/<rarity>/`側に既にベースの宝箱＋そのレア度のVFXが合成済みのため、そちらだけで単独再生できる

各フレームの表示時間（ms）は元データの生成スクリプト（`build_animations.py`）にある`DURATIONS = [180, 80, 80, 90, 100, 120, 140, 180, 420]`をそのまま`FRAME_DURATIONS_MS`として踏襲している（最後のフレームだけ長め＝開封後の余韻）。

## 画面の流れ

1. **待機状態**：中央に閉じた宝箱（`frame_00`、レア度VFX無しなので見た目はどのレア度でも共通）を表示。「宝箱をタップして開ける」と案内
2. **タップ**：レア度5種（`C`/`B`/`A`/`S`/`SS`）から均等ランダムに1つ選び（ドロップ率は未定のため仮に均等）、そのレア度の`frame_00`〜`frame_08`を`FRAME_DURATIONS_MS`の間隔で順番に表示する（`setTimeout`ベースのPromiseチェーン、戦闘画面の演出と同じ方式）
3. **結果表示**：最終フレーム（宝箱が開いて光っている状態）で静止し、その下に「\<レア度\>ランクのアイテムを獲得！」をレア度ごとの色（下表）で表示する
4. 結果表示から少し間（`RESULT_HOLD_MS`=900ms）を置いた後、再び宝箱をタップして次を引ける（連打で演出が壊れないよう、演出中〜余韻中はボタンを`disabled`にしている）

レア度ごとの表示色（`RARITY_LABEL_COLOR`、元データの主光色に合わせた仮の値）：

| レア度 | 色 |
| --- | --- |
| C | 灰白 `#dce2e8` |
| B | 緑 `#5be08a` |
| A | 青 `#5fb1ff` |
| S | 紫 `#c983ff` |
| SS | 金 `#ffc25c` |
