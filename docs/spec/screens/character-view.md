# キャラクター確認画面（`/games/game1/character`）

実装: [app/games/game1/(main)/character/page.tsx](<../../../app/games/game1/(main)/character/page.tsx>)、キャラクターデータ: [lib/characters.ts](../../../lib/characters.ts) / [lib/characters-info.ts](../../../lib/characters-info.ts)、装備データ: [lib/game1-data.ts](../../../lib/game1-data.ts)

## 概要

下部ナビゲーションバー（[bottom-nav.md](./bottom-nav.md)）の「仲間」タブから切り替わる、キャラクターの立ち絵を1人ずつ確認する画面。スマホを縦向きに持った状態を前提にしたデザイン。上（ステータス）／中央（立ち絵）／下（装備スロット）の3段構成で、**スワイプで動くのは中央の額縁の中身（立ち絵）だけ**で、上下のUIは固定されている。

## 画面構成

1. **上部：ステータス表示＋バトル参加チェックボックス**
   - 現在選択中のキャラクターのステータスを表示。上段に「レベル」（`characterLevels`、未設定は1として扱う）を単独表示し、その下を2段組み（`grid-cols-2`）で HP／会心率、攻撃力／会心ダメージ、防御力／属性耐性 の3行を並べる
     - HP・攻撃力・防御力は[lib/characters.ts](../../../lib/characters.ts)の`CHARACTERS`から取得（現時点では全て仮の値）
     - 会心率（10%固定）・会心ダメージ（150%固定）・属性耐性（0%固定）は現状すべて装備なしの基礎値のプレースホルダー（アーティファクトなどによる加算は未実装）
   - その下に「バトルに参加」チェックボックス（詳細は下記「編成（バトルに参加）」参照）
2. **中央：額縁つきのドット絵待機アニメーション**
   - 黒縁＋クリーム色のマット風の額縁（`border`と`box-shadow`のみで表現。装飾画像は使っていない）の中に、現在のキャラクターのドット絵を表示する。素材の出所・仕様は、このアプリのリポジトリ外にある画像制作用リポジトリ（`hirogames_images/CHARACTER_SCREEN_ASSETS.md`）で管理されている
   - 各キャラクター1枚のスプライトシート（`public/characters/idle/c{ID}_idle_sheet.png`、486×810px相当のコマを8列×5行=40コマ並べたもの）をCSSの`background-position`で100msごとに切り替え、瞬きや髪・炎・光の粒などがゆっくり動く待機アニメーションとしてループ表示する（4秒で1周、`IDLE_FRAME_COUNT`/`IDLE_FRAME_DURATION_MS`）。フレーム送りは`setInterval`ベース（画面全体で1つのタイマーを共有し、表示中の前後3キャラクター分の額縁を同期させている）
   - 顔・胸・お腹・腰・足元の位置はコマ間で固定という素材側の仕様のため、切り替わっても違和感のないループになる。拡大時も`image-rendering: pixelated`でドットの角を保っている
   - 額縁はスプライト1コマの縦横比（486:810）に合わせたサイズだが、額縁の縁（マット風のinset box-shadow）にキャラクターが重ならないよう、あえて額縁より一回り小さく（94%）表示している。等倍（100%）で表示すると、足元など余白の少ない部分が縁と重なって見切れることがあったため
3. **下部：装備スロット**
   - 4枠を横並びで表示。**一番左が武器スロット、残り3枠がアーティファクトスロット**（[items.md](../items.md)参照）
   - 空欄は「＋」表示の点線枠。装備しているスロットはアイテムアイコンを表示する
   - 下部ナビゲーションバーと重ならないよう、下側に余白を空けている

## 表示対象は「仲間になっているキャラクター」だけ

[冒険システム設計](../adventure-system.md#キャラクターの仲間解放)の通り、キャラクターはステージクリアで順次仲間になる（`maxClearedStage`で判定）。この画面のスワイプ対象は**まだ仲間になっていないキャラクターを含まない**（`lib/characters.ts`の`CHARACTERS`全4体のうち、解放済みのものだけに絞り込む）。序盤はアカネ1人だけがループする状態になる。

## 編成（バトルに参加）

- ステータス表示の下にあるチェックボックス「バトルに参加」で、そのキャラクターを編成に入れるかどうかを切り替える。最大3人まで（`MAX_PARTY_SIZE`）
- 4人揃うまでは、新しく仲間になったキャラクターは自動でチェックON（`syncActivePartyWithUnlocks()`、画面を開くたびに同期）。あえて外すことは可能
- すでに3人編成済みの状態で4人目を追加しようとすると、チェックボックスの右側に「最大3人まで」と一瞬表示されて弾かれる（他の誰かを先に外す必要がある）
- 保存先：[lib/game1-data.ts](../../../lib/game1-data.ts)の`Game1SaveData.activePartyIds`
- 専用の編成画面は無く、この画面のチェックボックスだけで完結する簡易な仕様（[adventure-system.md](../adventure-system.md)参照）

## スワイプ操作

- 額縁の中でドラッグ（`onPointerDown` / `onPointerMove` / `onPointerUp`、Pointer Events）すると、額縁の中身（前・現在・次の3人分の待機アニメーションを横に並べたトラック）だけが指の動きに追従してリアルタイムにスライドする。額縁自体や上下のステータス・育成メニューは動かない
  - **左**にスワイプ → 次のキャラクターへ（解放済みキャラクターの中でループ）
  - **右**にスワイプ → 前のキャラクターへ（逆順）
  - ドラッグの横移動量が60px（`SWIPE_THRESHOLD`）を超えた状態で指を離すと、そのまま額縁の外まで滑って次/前のキャラクターに切り替わる（250ms、`SNAP_DURATION`）。届かなければ元の位置にスナップバックして切り替わらない
  - 切り替え後、トラックの位置を（アニメーション無しで）中央に瞬時にリセットすることで、無限ループしているように見せている
- **キャラクターが完全に切り替わったタイミング（スライド完了後）で、上部のステータス表示（HP/攻撃力/防御力）も新しいキャラクターの値に切り替わる**。ドラッグ中は元のキャラクターの値のまま変化しない
- この画面はスクロール不要なため、`touch-action: none`（Tailwindの`touch-none`）を画面全体と額縁の両方に指定し、上下方向のブラウザ標準スワイプ（スクロール）を無効化している。左右のスワイプ判定はブラウザの標準機能ではなく自前のPointer Events処理で行っているため、これで干渉せず動作する

## 装備の操作

- 空欄・装備済みどちらのスロットをタップしても、その枠に装備できるアイテムの選択シート（画面下からせり上がるボトムシート、[bag.md](./bag.md)の詳細シートと同じ形式）が開く
  - 武器スロット：現在のキャラクターの`weaponType`（[characters-info.ts](../../../lib/characters-info.ts)）と一致する、**所持している**アイテムだけを候補にする
  - アーティファクトスロット：`type`が「アーティファクト」の所持アイテムを候補にする。**同じキャラクターの他のアーティファクトスロットに装備済みのものは候補から除外**する（同じ物を2箇所に付けられないようにするため）
  - 候補をタップするとその場で装備され、シートが閉じる
  - スロットに何か装備されている状態でシートを開くと、右上に「外す」ボタンが出る（タップでそのスロットを空にする）
  - 候補が0件のときは「装備できる武器/アーティファクトを持っていません」と表示する
- 装備は**キャラクターごと**に記録する（`Game1SaveData.equipment`、キャラID→装備の対応）。スワイプで別のキャラクターに切り替えると、そのキャラクター自身の装備状況に表示が変わる
- 同じアイテムを複数のキャラクターに同時に装備させることについては、現状チェックしていない（今後の検討事項）

## 今後

- ステータスの値は全キャラクター仮の数値。正式な数値・バランス調整は別途行う
- 会心率・会心ダメージ・属性耐性は現状すべて固定のプレースホルダー値。装備・キャラクター個性による変動は未実装
- 装備によるステータスへの加算（攻撃力アップなど）は未実装。今は「はめ込まれる」見た目だけで、ステータス表示には反映されない
- スキルは「一旦邪魔なので消してほしい」との指示で今回のボタンごと削除した。中身は別途検討する
- 同じアイテムを複数キャラクターへ同時装備できてしまう点、装備すると所持数からアイテムを引くべきか（引かない仕様で現状は実装）などは、今後のバランス設計とあわせて決める
- キャラクターの名前・プロフィールなど、ステータス以外の表示項目は未定
- 待機アニメーションは4人分とも同じ8列×5行・40コマ・100ms間隔の仕様で揃っているが、素材側（`hirogames_images`リポジトリ）が更新された場合は`public/characters/idle/`配下の該当ファイルを差し替えるだけで反映される
