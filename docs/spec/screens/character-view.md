# キャラクター確認画面（`/games/game1/character`）

実装: [app/games/game1/character/page.tsx](../../../app/games/game1/character/page.tsx)

## 概要

Game1画面の「キャラクター」ボタンから遷移する、キャラクターの立ち絵を1人ずつ確認する画面。スマホを縦向きに持った状態を前提にしたデザイン。

## 表示・操作

- 画面中央に、現在選択中のキャラクターの立ち絵（`public/characters/c{ID}_t01.png`）を1枚、画面に収まる大きさで表示する
- 前・現在・次の3枚を横に並べたトラックをドラッグ量に応じてリアルタイムに動かし、指の動きに追従してスライドする
  - **左**にスワイプ → 次のキャラクターへ（`c01 → c02 → c03 → c04 → c01 …` の順）
  - **右**にスワイプ → 前のキャラクターへ（逆順）
  - ドラッグの横移動量が60px（`SWIPE_THRESHOLD`）を超えた状態で指を離すと、そのまま画面外まで滑って次/前のキャラクターに切り替わる（250ms、`SNAP_DURATION`）。届かなければ元の位置にスナックバックして切り替わらない
  - 実装は `onPointerDown` / `onPointerMove` / `onPointerUp`（Pointer Events）。タッチ・マウス・ペンいずれでも同じ処理で動く
  - 切り替え後、トラックの位置を（アニメーション無しで）中央に瞬時にリセットすることで、無限ループしているように見せている
- 画面右上に、Game1のメイン画面（`/games/game1`）に戻るための丸いアイコンボタン（✕）を固定表示する
