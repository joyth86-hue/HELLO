# キャラクター確認画面（`/games/game1/character`）

実装: [app/games/game1/(main)/character/page.tsx](<../../../app/games/game1/(main)/character/page.tsx>)、キャラクターデータ: [lib/characters.ts](../../../lib/characters.ts) / [lib/characters-info.ts](../../../lib/characters-info.ts)、装備データ: [lib/game1-data.ts](../../../lib/game1-data.ts)

## 概要

下部ナビゲーションバー（[bottom-nav.md](./bottom-nav.md)）の「仲間」タブから切り替わる、キャラクターの立ち絵を1人ずつ確認する画面。スマホを縦向きに持った状態を前提にしたデザイン。上（ステータス）／中央（立ち絵）／下（装備スロット）の3段構成で、**スワイプで動くのは中央の額縁の中身（立ち絵）だけ**で、上下のUIは固定されている。

## 画面構成

1. **上部：ステータス表示**
   - 現在選択中のキャラクターの `HP` / `攻撃力` / `防御力` を表示（[lib/characters.ts](../../../lib/characters.ts) の `CHARACTERS` から取得。現時点では全て仮の値）
2. **中央：額縁つきの立ち絵**
   - 黒縁＋クリーム色のマット風の額縁（`border`と`box-shadow`のみで表現。装飾画像は使っていない）の中に、現在のキャラクターの立ち絵（`public/characters/c{ID}_t01.png`）を表示する
   - 額縁は立ち絵の縦横比（2:3）に合わせたサイズで、上下の余白を最小限にしている
3. **下部：装備スロット**
   - 4枠を横並びで表示。**一番左が武器スロット、残り3枠がアーティファクトスロット**（[items.md](../items.md)参照）
   - 空欄は「＋」表示の点線枠。装備しているスロットはアイテムアイコンを表示する
   - 下部ナビゲーションバーと重ならないよう、下側に余白を空けている

## スワイプ操作

- 額縁の中でドラッグ（`onPointerDown` / `onPointerMove` / `onPointerUp`、Pointer Events）すると、額縁の中身（前・現在・次の3枚の立ち絵を横に並べたトラック）だけが指の動きに追従してリアルタイムにスライドする。額縁自体や上下のステータス・育成メニューは動かない
  - **左**にスワイプ → 次のキャラクターへ（`c01 → c02 → c03 → c04 → c01 …` の順）
  - **右**にスワイプ → 前のキャラクターへ（逆順）
  - ドラッグの横移動量が60px（`SWIPE_THRESHOLD`）を超えた状態で指を離すと、そのまま額縁の外まで滑って次/前のキャラクターに切り替わる（250ms、`SNAP_DURATION`）。届かなければ元の位置にスナップバックして切り替わらない
  - 切り替え後、トラックの位置を（アニメーション無しで）中央に瞬時にリセットすることで、無限ループしているように見せている
- **キャラクターが完全に切り替わったタイミング（スライド完了後）で、上部のステータス表示（HP/攻撃力/防御力）も新しいキャラクターの値に切り替わる**。ドラッグ中は元のキャラクターの値のまま変化しない
- この画面はスクロール不要なため、`touch-action: none`（Tailwindの`touch-none`）を画面全体と額縁の両方に指定し、上下方向のブラウザ標準スワイプ（スクロール）を無効化している。左右のスワイプ判定はブラウザの標準機能ではなく自前のPointer Events処理で行っているため、これで干渉せず動作する

## 装備の操作

- 空欄・装備済みどちらのスロットをタップしても、その枠に装備できるアイテムの選択シート（画面下からせり上がるボトムシート、[bag.md](./bag.md)の詳細シートと同じ形式）が開く
  - 武器スロット：現在のキャラクターの`weaponType`（[characters-info.ts](../../../lib/characters-info.ts)）と一致する、**所持している**アイテムだけを候補にする
  - アーティファクトスロット：`type`が「アーティファクト」の所持アイテムを候補にする。**同じキャラクターの他のアーティファクトスロットに装備済みのものは候補から除外**する（同じ物を2箇所に付けられないようにするため）
  - 候補をタップするとその場で装備され、シートが閉じる
  - スロットに何か装備されている状態でシートを開くと、右上に「外す」ボタンが出る（タップでそのスロットを空にする）
  - 候補が0件のときは「装備できる武器/アーティファクトを持っていません」と表示する
- 装備は**キャラクターごと**に記録する（`Game1SaveData.equipment`、キャラID→装備の対応）。スワイプで別のキャラクターに切り替えると、そのキャラクター自身の装備状況に表示が変わる
- 同じアイテムを複数のキャラクターに同時に装備させることについては、現状チェックしていない（今後の検討事項）

## 今後

- ステータスの値は全キャラクター仮の数値。正式な数値・バランス調整は別途行う
- 装備によるステータスへの加算（攻撃力アップなど）は未実装。今は「はめ込まれる」見た目だけで、ステータス表示には反映されない
- スキルは「一旦邪魔なので消してほしい」との指示で今回のボタンごと削除した。中身は別途検討する
- 同じアイテムを複数キャラクターへ同時装備できてしまう点、装備すると所持数からアイテムを引くべきか（引かない仕様で現状は実装）などは、今後のバランス設計とあわせて決める
- キャラクターの名前・プロフィールなど、ステータス以外の表示項目は未定
