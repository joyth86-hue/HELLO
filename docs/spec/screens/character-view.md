# キャラクター確認画面（`/games/game1/character`）

実装: [app/games/game1/character/page.tsx](../../../app/games/game1/character/page.tsx)、キャラクターデータ: [lib/characters.ts](../../../lib/characters.ts)

## 概要

Game1画面の「キャラクター」ボタンから遷移する、キャラクターの立ち絵を1人ずつ確認する画面。スマホを縦向きに持った状態を前提にしたデザイン。上（ステータス）／中央（立ち絵）／下（育成メニュー）の3段構成で、**スワイプで動くのは中央の額縁の中身（立ち絵）だけ**で、上下のUIは固定されている。

## 画面構成

1. **上部：ステータス表示**
   - 現在選択中のキャラクターの `HP` / `攻撃力` / `防御力` を表示（[lib/characters.ts](../../../lib/characters.ts) の `CHARACTERS` から取得。現時点では全て仮の値）
   - 右上に固定の閉じるボタン（✕、Game1のメイン画面 `/games/game1` に戻る）と重ならないよう、右側に余白を空けている
2. **中央：額縁つきの立ち絵**
   - 黒縁＋クリーム色のマット風の額縁（`border`と`box-shadow`のみで表現。装飾画像は使っていない）の中に、現在のキャラクターの立ち絵（`public/characters/c{ID}_t01.png`）を表示する
   - 額縁は立ち絵の縦横比（2:3）に合わせたサイズで、上下の余白を最小限にしている
3. **下部：育成メニュー**
   - 「装備」「スキル」の2つのボタン（現時点では見た目のみで、押しても何も起きない）

## スワイプ操作

- 額縁の中でドラッグ（`onPointerDown` / `onPointerMove` / `onPointerUp`、Pointer Events）すると、額縁の中身（前・現在・次の3枚の立ち絵を横に並べたトラック）だけが指の動きに追従してリアルタイムにスライドする。額縁自体や上下のステータス・育成メニューは動かない
  - **左**にスワイプ → 次のキャラクターへ（`c01 → c02 → c03 → c04 → c01 …` の順）
  - **右**にスワイプ → 前のキャラクターへ（逆順）
  - ドラッグの横移動量が60px（`SWIPE_THRESHOLD`）を超えた状態で指を離すと、そのまま額縁の外まで滑って次/前のキャラクターに切り替わる（250ms、`SNAP_DURATION`）。届かなければ元の位置にスナップバックして切り替わらない
  - 切り替え後、トラックの位置を（アニメーション無しで）中央に瞬時にリセットすることで、無限ループしているように見せている
- **キャラクターが完全に切り替わったタイミング（スライド完了後）で、上部のステータス表示（HP/攻撃力/防御力）も新しいキャラクターの値に切り替わる**。ドラッグ中は元のキャラクターの値のまま変化しない
- この画面はスクロール不要なため、`touch-action: none`（Tailwindの`touch-none`）を画面全体と額縁の両方に指定し、上下方向のブラウザ標準スワイプ（スクロール）を無効化している。左右のスワイプ判定はブラウザの標準機能ではなく自前のPointer Events処理で行っているため、これで干渉せず動作する

## 今後
