# スタート画面（`/`）

実装: [app/page.tsx](../../../app/page.tsx)

## 概要

アプリを開いたときに最初に表示される画面。ロゴ表示に加えて、初回起動時のユーザー名登録もこの画面で行う。

## 表示要素

- タイトルロゴ：「あきくんゲームズ」（[Logo.tsx](../../../components/Logo.tsx)、手書き風フォント。詳細は[../visual-design.md](../visual-design.md)参照）。画面表示時にフェード＋浮き上がりの演出付き
- 画面左上：2回目以降の起動時、`ログイン名：○○（登録済みのユーザー名）` を表示（初回登録前は非表示）
- 状態に応じて、以下のいずれかをロゴの下に表示する
  1. 初回起動時：名前入力フォーム
  2. 名前確認ダイアログ
  3. 通常時：Startボタン

Startボタンをタップすると `/menu`（ゲームメニュー画面）に遷移する。

## 初回起動時のユーザー名登録フロー

詳細な仕様は [../user-profile.md](../user-profile.md) を参照。この画面はそのフローの入力・確認UIを表示する場所。

## 状態遷移（画面内部）

- `checking`：保存済みのユーザー名があるか確認中（一瞬なので何も表示しない）
- `onboarding-input`：ユーザー名未登録 → 名前入力フォームを表示
- `onboarding-confirm`：入力後、確認ダイアログを表示
- `ready`：ユーザー名登録済み → 通常のスタート画面（Startボタン）を表示
