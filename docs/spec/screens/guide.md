# 図鑑画面（`/games/game1/guide`）

実装: [app/games/game1/guide/page.tsx](../../../app/games/game1/guide/page.tsx)

## 概要

[ホーム画面](./game1-home.md)の「図鑑」ボタンから遷移する、**冒険してきた記録を見る画面**。下部ナビゲーションバー（[bottom-nav.md](./bottom-nav.md)）の5画面には含まれず、独立したページとして戻るボタン（`ui_back`）付きで表示する（バッグの中身画面のような「今持っているもの」の確認ではなく、実績・図鑑としての性格が強いため）。

上部の3タブ（実績／装備／BGM）で表示を切り替える。いずれのタブも、[テストモード](../test-mode.md)の解放判定（`getEffectiveGame1Data`）は使わず、**常に実際のセーブデータをそのまま表示する**（テストモードで実績や図鑑の埋まり方が誤魔化されないようにするため）。

## ①実績タブ

現在3種類の実績を、ラベルと値を横並びにしたカードで縦に並べて表示する（今後種類が増える想定）。

| ラベル | 値 | データソース |
| --- | --- | --- |
| 到達ステージ | `{maxClearedStage} / 100` | `Game1SaveData.maxClearedStage`（100は[冒険システム設計](../adventure-system.md)の「100ステージクリアをゴール」に合わせた固定値） |
| 入手アイテム数 | `{unlockedItemIds.length} / {全アイテム数}` | `Game1SaveData.unlockedItemIds`（下記「装備タブ」参照）／全アイテム数は[lib/items-info.ts](../../../lib/items-info.ts)の`ITEM_BASE_INFO.length`（250） |
| ステージクリア数 | `{totalBossClears}回` | `Game1SaveData.totalBossClears`（周回クリアも含む累計。詳細は[save-data.md](../save-data.md)参照） |

## ②装備タブ

全アイテム（[lib/items-info.ts](../../../lib/items-info.ts)の`ITEM_BASE_INFO`、250件）の枠を種類タブ（すべて／片手剣／法器／弓／アーティファクト、バッグの中身画面と同じ構成）付きの**5列**グリッドで並べる。

- 一度でも入手したことのあるアイテム（`Game1SaveData.unlockedItemIds`に含まれる）は、通常のアイコン画像を表示し、タップするとバッグの中身画面と同じ形式の詳細シート（アイコン・名称・種類またはslot・レアリティ・説明文）が開く
- 未入手のアイテムは画像を出さず、枠だけ（暗めの背景＋「？」）を表示する。タップしても反応しない（`disabled`）
- 冒険を進めるほど埋まっていく「図鑑」としての見せ方（ユーザー確認済み）
- `unlockedItemIds`は現在**所持しているかどうか（`inventory`）とは無関係**。合成で個体を使い切って手元に0個になっても、一度入手していれば埋まったまま表示され続ける

## ③BGMタブ

ゲーム内で使っている全BGM（[lib/audio-tracks.ts](../../../lib/audio-tracks.ts)の`ALL_BGM_TRACKS`、14曲）を曲名付きで縦一覧表示する。詳細は[audio.md](../audio.md#bgm一覧視聴図鑑画面)参照。

- タップで再生、再度タップで停止（同時に2曲は鳴らない。他の曲をタップすると自動的に切り替わる）
- 聴いたことがあるかどうかに関わらず全曲再生できる（ユーザー確認済みの割り切り）
- 設定のBGM ON/OFFとは独立した専用の再生（試聴用のため）

## 今後

- 実績の種類はユーザーの希望により今後増える可能性がある（カード形式で並べているため、追加は比較的容易な想定）
- 装備タブで「どのキャラが今装備しているか」などの追加情報を出すかは未定
- BGMタブに「聴いたことがある曲かどうか」の判定・表示を加えるかは未定（まずは全曲再生できる形で実装、ユーザー確認済み）
