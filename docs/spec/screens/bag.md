# バッグの中身画面（`/games/game1/bag`）

実装: [app/games/game1/bag/page.tsx](../../../app/games/game1/bag/page.tsx)

## 概要

[Game 1ホーム画面](./game1-home.md)の「バッグの中身」から遷移する、所持アイテムの一覧・確認画面。図鑑（全アイテムを見る画面）ではなく、**実際に持っているものだけ**を表示する。

## 表示要素

- 見出し「バッグの中身」、所持アイテムの種類数
- 右上に✕ボタン（[キャラクター確認画面](./character-view.md)と同じスタイル）→ ホーム画面に戻る
- 所持アイテムを4列のグリッドで表示。各カードはアイコン画像のみで、所持数が2個以上のものは右下に「×N」バッジを重ねる
- カードをタップすると、その下に詳細カード（アイコン・名称・種類またはslot・レアリティ・所持数・説明文）を表示する。未選択時は「アイテムをタップすると詳細が表示されます」という案内文を表示

## データ

- アイテムの基本情報（名称・説明文・種類・レアリティ・画像パス）は[items.md](../items.md) / [lib/items-info.ts](../../../lib/items-info.ts)を参照
- 所持数は[lib/game1-data.ts](../../../lib/game1-data.ts)の`Game1SaveData.inventory`（`{ itemId, quantity }`の配列）で管理する。詳細は[save-data.md](../save-data.md)参照
