# バッグの中身画面（`/games/game1/bag`）

実装: [app/games/game1/bag/page.tsx](../../../app/games/game1/bag/page.tsx)

## 概要

下部ナビゲーションバー（[bottom-nav.md](./bottom-nav.md)）の「バッグ」タブから切り替わる、所持アイテムの一覧・確認画面。図鑑（全アイテムを見る画面）ではなく、**実際に持っているものだけ**を表示する。

## レイアウトの検討経緯

所持アイテムが将来100個を超える前提で、[Artifactで3つのレイアウト案（連続スクロール／種類タブ／レアリティ別グループ）](https://claude.ai/code/artifact/ad8ae16b-effc-4e9e-879e-ca59177b89e6)を作って比較検討した。**種類タブで絞り込む案（案B）を採用**。目的の武器種を装備させたいときに探しやすいことが決め手。

## 表示要素

- 見出し「バッグの中身」、所持数（現在の個体数 / 上限100）
- 見出し下に種類タブ（すべて／片手剣／法器／弓／アーティファクト）。各タブに所持している個体数を表示し、タップで絞り込む
- 絞り込んだアイテムを**8列**のグリッドで表示。**アイテムは個体（インスタンス）単位で管理しているため、同じ種類のアイテムを複数持っていても1個体＝1カードとして別々に並ぶ**（「×N」のような所持数バッジではない）。合成で強化済み（`plus`が1以上）の個体は右下に「+N」バッジを重ねる。下部ナビゲーションバーと重ならないよう、グリッドの下に余白を空けている
- カードをタップすると、画面下からシート状の詳細（アイコン・名称（強化済みなら+N併記）・種類またはslot・レアリティ（色分けバッジ）・説明文）がせり上がる。シート表示中は背景を暗くし、暗い部分をタップすると閉じる（下部ナビゲーションバーより手前・高いz-indexで表示するため、ナビバーごと覆い隠す）
- グリッド部分のみが縦スクロールする（見出し・タブは固定）

## データ

- アイテムの基本情報（名称・説明文・種類・レアリティ・画像パス）は[items.md](../items.md) / [lib/items-info.ts](../../../lib/items-info.ts)を参照
- 所持アイテムは[lib/game1-data.ts](../../../lib/game1-data.ts)の`Game1SaveData.inventory`（`ItemInstance`の配列、個体ごとに`instanceId`・`itemId`・`plus`を持つ）で管理する。個体管理・上限100・合成の詳細は[items.md](../items.md#アイテムの個体管理合成のための前提)、データ構造の詳細は[save-data.md](../save-data.md)参照
