# Game 1 ホーム画面（`/games/game1/home`）

実装: [app/games/game1/(main)/home/page.tsx](<../../../app/games/game1/(main)/home/page.tsx>)

## 概要

[Game 1開始画面](./game1.md)でタップした後に表示される、Game1のメイン画面。他画面（[character-view.md](./character-view.md)、[bag.md](./bag.md)）が使う[流れる文字パターンの共通背景](../visual-design.md#背景流れる文字パターン)（`GameBackground`）とは別に、この画面専用の背景イラストを敷いている。

## 背景イラスト

仲間の拠点（ギルドホール風の部屋）のイラストで、**編成している仲間の人数に応じて背景に描かれるキャラクターの人数も増える**想定（`home_01`=1人〜`home_04`=4人）。画像は[public/backgrounds/home/](../../../public/backgrounds/home/)に4種類（`home_01_akane.png` / `home_02_akane_koyuki.png` / `home_03_akane_koyuki_kaede.png` / `home_04_akane_koyuki_kaede_sayumi.png`）が揃っている。

[バトルに参加する編成（`activePartyIds`）](../adventure-system.md#編成バトルに参加)自体はできたが、まだ背景画像の切り替えとは連動しておらず、**現状は`home_04`（4人とも揃った版）で固定**している（テスト目的、`HOME_BACKGROUND`定数）。

## 表示要素

- 右上：所持金（共通通貨、全ゲーム共有）と経験値（`expPoints`、`game1`のセーブデータ）を2行で表示する小さなパネル（`所持金：XXXモラ` / `経験値：YYYpt`）。背景イラストの上でも読めるよう、不透明度の高いダークガラス風のパネルにしている
- 画面上半分の右端（カエデの横の空きスペース）：導線ボタン4つを縦並びで配置。上から「プレゼント」「デイリーミッション」「図鑑」「設定」（[共通UIボタン素材](../ui-buttons.md)の`ui_present` / `ui_daily_missions` / `ui_guide` / `ui_settings`を使用、56px角）。**「プレゼント」のみ、[テストモード](../test-mode.md)切り替え用の「コードを入力」シートを開く。残り3つは配置のみでタップしても何も起きない**（各機能は未実装）
- 見出しや共通通貨カードなどの装飾要素は表示せず、上記パネル・導線ボタンと下部の「冒険に行く」ボタンのみのシンプルな構成にしている（画面を開くたびにプレイ回数`playCount`は+1しセーブデータに保存しているが、画面上には表示しない）
- 「冒険に行く」ボタン：画面下部（`mt-auto`で下寄せ）に配置。[ステージ選択画面](./stages.md)（`/games/game1/stages`）へ遷移する
- 画面下部には[下部ナビゲーションバー](./bottom-nav.md)が常時表示される（この画面固有のボタンではなく、マップ/ショップ/仲間/バッグと共通のもの。このホーム画面自体が「冒険」タブに対応する）

## 今後

- 右端の4つの導線ボタン（プレゼント・デイリーミッション・図鑑・設定）の実装（画面遷移・機能）は未着手
- 「冒険」タブ（＝このホーム画面）の中身は、拠点機能の見せ方が決まり次第この仕様書と実装を更新する。
- 背景イラスト（`home_04`）だと、下部ナビゲーションバー導入前は「キャラクター」「バッグの中身」ボタンの端がキャラクターの頭に軽く重なっていた。ナビゲーションバーへの移行でボタン自体が画面下部に集約されたため、その重なりは解消している。
- `activePartyIds`（バトルに参加している人数・顔ぶれ）に応じて`HOME_BACKGROUND`を`home_01`〜`home_04`から動的に選ぶよう変更する。
- 「ゲームを終了」（`/`に戻る）ボタンは、下部ナビゲーションバーへの移行にあたって一旦なくなった。必要であれば別の場所（設定画面など）に置き直すことを検討する。
