# ステージ選択画面（`/games/game1/stages`）

実装: [app/games/game1/(main)/stages/page.tsx](<../../../app/games/game1/(main)/stages/page.tsx>)

## 概要

[Game 1ホーム画面](./game1-home.md)の「冒険に行く」ボタンから遷移する、挑戦するステージを選ぶ画面。[冒険システム設計](../adventure-system.md)の一部。下部ナビゲーションバーの管理下（`(main)`ルートグループ内）にあり、他画面と同様にバーは常時表示される。

## 表示要素

- 見出し「ステージ選択」のみ（クリア済みステージ数などの補足テキストは表示しない）
- 選べるステージ（クリア済みの全ステージ＋未クリアの最新1ステージ）を、新しい番号が上に来る順で縦一覧表示。各行はステージ番号とバッジのみのシンプルな構成（説明文は表示しない）
  - クリア済み：紫系の「CLEAR」バッジ
  - 未クリア（一番上に出てくる、挑戦可能な次のステージ）：オレンジ系の「TRY」バッジ（クリア済みと区別できるよう背景色を変えている）
- 各行をタップすると `/games/game1/battle?stage=<ステージ番号>` に遷移する

## 現状の簡易実装（今後差し替え）

- 遷移先は現状、[戦闘画面・動作確認版](./battle-test.md)（`/games/game1/battle`）のまま。渡した`stage`パラメータは、勝利時に`maxClearedStage`を更新するためだけに使われており、**そのステージ本来の敵構成・10バトル連戦・背景はまだ反映されない**（常に同じ仮の3v3・1バトルの戦闘になる）
- ステージの推奨戦力や敵構成のプレビューは無し、番号と挑戦可否だけのシンプルな一覧
