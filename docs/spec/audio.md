# 音声（BGM・効果音）

## 元データ・取り込み方

BGMの元ファイルは、このアプリのリポジトリ直下の`/音楽`フォルダ（ユーザーが随時曲を置いていく作業用の置き場、`.gitignore`済みでリポジトリには含まれない）に置かれる。[characters.md](./characters.md)の`サンプル画像/`・[items.md](./items.md)の元画像フォルダと同様、**このフォルダの中身は消したり移動したりせず、実際に使う曲だけを選んで`public/audio/`へコピーして使う**（置かれた曲を全部自動的に取り込むわけではない）。

- コピー先：[public/audio/bgm/](../../public/audio/bgm/)（1画面1曲、ファイル名はローマ字化した曲名。例：「穏やかなとき.mp3」→`odayakana-toki.mp3`）
- どの曲をどの画面で使うかは、その都度ユーザーから指示を受けて決める。指示が無い曲はまだ用途未定として取り込まない

## BGM再生（`components/BgmPlayer.tsx`）

- 画面（ページ）ごとに`<BgmPlayer src="/audio/bgm/xxx.mp3" enabled={bgmEnabled} />`を置く形。`src`が変わった時だけ`new Audio()`で読み込み直し（`loop = true`、音量は`BGM_VOLUME`＝0.5固定の仮値）、`enabled`の変化には`play()`/`pause()`だけで反応する（`pause()`は再生位置を保持するので、OFF→ONで曲の途中から再開できる）
- **BGMは画面に紐づく**。今のところ横断的に鳴らし続ける仕組みは無いため、その画面を離れる（アンマウントされる）と音も止まる。例えばホーム画面からバッグ画面へ切り替えるとホームのBGMは止まる。複数画面をまたいで鳴らし続けたくなったら、`app/games/game1/(main)/layout.tsx`側に引き上げるなど別途検討する
- ブラウザの自動再生ポリシーにより、直前にユーザー操作が無いと`play()`が拒否されることがある。失敗しても例外は投げず、単に鳴らないだけにしている（再試行はしない）
- 現在、実際にBGMが設定されているのはホーム画面（`/games/game1/home`）のみ。`HOME_BGM_SRC`定数で指定している

## 設定（BGM・効果音のON/OFF）

実装: [lib/storage.ts](../../lib/storage.ts)の`GlobalSaveData.bgmEnabled`/`seEnabled`（**全ゲーム共有**のデータ。通貨と同じ扱い）、ホーム画面の「設定」アイコンから開く設定シート（[game1-home.md](./screens/game1-home.md#設定)参照）。

- BGM・効果音それぞれに`components/ToggleSwitch.tsx`（iOS風の丸いつまみのON/OFFスイッチ、汎用コンポーネント）を使ったトグルを表示する
- **BGMは実際に音の再生/停止に反映される**（`BgmPlayer`の`enabled`prop経由）
- **効果音は現状、鳴らす効果音自体が実装されていない**ため、UIのトグルと保存だけ用意している（ユーザー確認済み：まずは設定UIだけ先に作っておく）。効果音システムを実装する際は、各効果音の再生前に`loadGlobalData().seEnabled`を見て鳴らすかどうか判定する想定
