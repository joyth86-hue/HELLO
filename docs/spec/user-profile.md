# ユーザー名登録・ログイン表示

実装: [app/page.tsx](../../app/page.tsx)（UI）、[lib/storage.ts](../../lib/storage.ts)（保存処理）

## 概要

このユーザー（＝このブラウザ）にとっての初回起動時に、ゲーム内で使うユーザー名を登録させる。登録済みかどうかは共有セーブデータ（`GlobalSaveData.userName`）で判定する。

## 初回起動時のフロー（スタート画面）

1. `userName` が未登録（空文字）の場合、以下を表示する。
   - 「あなたのお名前は？」というラベル
   - テキスト入力欄（最大20文字）
   - その下に「OK」ボタン（未入力時は押せない）
2. 「OK」を押すと、確認ダイアログに切り替わる。
   - 「（入力した名前）さんでいいですか？」を表示
   - 「はい」「いいえ」の2択ボタンを表示
3. 「はい」を押した場合
   - 入力した名前を確定し、`setUserName()` でセーブデータに保存する
   - 通常のスタート画面（Startボタンあり）に切り替わる
4. 「いいえ」を押した場合
   - 確定をキャンセルし、名前入力フォームに戻る（入力済みの文字列は保持し、書き直せるようにする）

## 2回目以降の起動時

- `userName` が登録済みの場合、名前入力フローは表示しない。
- スタート画面の**左上**に `ログイン名：○○`（○○は登録済みのユーザー名）を表示する。

## 今後の検討事項

- 現状、名前の変更・リセット手段がない（一度登録すると変更不可）。設定画面などを作る際に変更機能を検討する。
- 名前のバリデーションは「空文字でないこと」のみ。不適切な文字列のチェックは未実装。
