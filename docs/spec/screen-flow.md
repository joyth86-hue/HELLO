# 画面構成・遷移フロー

各ゲームごとに専用の入り口画面を持つ構成にしている（複数ゲームをまとめるハブ画面は廃止した。経緯は[screens/start.md](./screens/start.md)参照）。

| パス | 画面名 | 説明 |
| --- | --- | --- |
| `/` | アプリ起動画面 | 黒背景→「hiro games」フェードイン→自動でGame1開始画面へ |
| `/games/game1` | Game 1 開始画面 | 背景＋タイトルのフェード演出のあと「タップして開始する」でホームへ |
| `/games/game1/home` | Game 1 ホーム画面（冒険タブ） | [screens/game1-home.md](./screens/game1-home.md)参照 |
| `/games/game1/map` | マップ画面 | 未実装（プレースホルダーのみ） |

| `/games/game1/character` | キャラクター確認画面（仲間タブ） | [screens/character-view.md](./screens/character-view.md)参照 |

上記5画面（ホーム/マップ/ショップ/キャラクター/バッグ）は、画面下部の[下部ナビゲーションバー](./screens/bottom-nav.md)（マップ/ショップ/冒険/仲間/バッグの5タブ）で直接切り替える構成になっている（以前の「ホーム画面から個別画面へ行って✕で戻る」構成から変更した）。

## 遷移フロー

```
/ (アプリ起動画面：黒背景→「hiro games」フェードイン、自動遷移)
  └─ 約2.5秒後、自動的に → /games/game1 (Game1開始画面：背景/タイトルのフェード演出)
                                └─ 演出後、画面タップ → 暗転＋Now Loading演出（約1.8秒）→ /games/game1/home (ホーム画面＝冒険タブ)
                                                            └─ 下部ナビゲーションバー（常時表示）で以下を直接切り替え
                                                                ├─ マップ → /games/game1/map（未実装）
                                                                ├─ ショップ → /games/game1/shop（未実装）
                                                                ├─ 冒険 → /games/game1/home
                                                                ├─ 仲間 → /games/game1/character
                                                                └─ バッグ → /games/game1/bag
                                                            └─ 「冒険に行く」→ /games/game1/stages (ステージ選択)
                                                                            └─ ステージをタップ → /games/game1/battle?stage=N（動作確認版の戦闘）
                                                                                            └─ 勝敗が決まると自動で /games/game1/home に戻る
```

## 入口ガード（`/games/game1`・`/games/game1/home`への直接アクセス対策）

ブックマークをホーム画面アイコンとして保存する際、iOSはその時点で開いていたURLをそのまま起動先として固定してしまう。もし`/games/game1`（開始画面）や`/games/game1/home`（ホーム画面）を開いている状態でブックマークを作ると、以後そのアイコンからは毎回`/`（起動画面の黒背景＋ロゴ演出）を経由せず直接それらの画面が開いてしまう不具合が実際に発生した。

対応として、この2画面（開始画面・ホーム画面）だけに「このタブでまだ`/`を経由していなければ`/`へ差し戻す」ガードを入れている（[lib/entry-guard.ts](../../lib/entry-guard.ts)の`useRequireSplashEntry`/`markEnteredViaSplash`）。判定は`sessionStorage`（タブを閉じるまで保持）で行うため、以下のように動く。

- ブックマーク等で`/games/game1`または`/games/game1/home`に**直接**（そのタブで初回）アクセス → `/`へ差し戻され、通常の起動フローをやり直す
- `/`を経由した後の、同じタブ内でのアプリ内遷移（開始画面→ホーム、下部ナビでのタブ切り替えなど）→ 一度`/`を通っていればガードには引っかからず、通常通り遷移する

**注意**：マップ・ショップ・キャラクター・バッグ・ステージ選択・戦闘画面にはこのガードを入れていない（意図的にスコープを絞った）。そのため、例えば`/games/game1/bag`を直接ブックマークして開いた場合、`/`を経由しないままそのタブでの`sessionStorage`は未設定になるが、この画面自体は表示される。そこから下部ナビの「冒険」タブでホームへ行こうとすると、ホーム側のガードに引っかかって`/`へ差し戻される（＝ガード対象外の画面から先にガード対象の画面へ内部遷移すると、想定外に差し戻される）。実運用上は稀なケースと判断し許容しているが、気になる場合は対象範囲を広げることを検討する。

## 現状の制約・未実装事項

- マップ・ショップ画面は未実装（タブとしては切り替わるが、中身は「準備中です」のプレースホルダーのみ）。
- 下部ナビゲーションバーへの移行にあたって、以前ホーム画面にあった「ゲームを終了」（`/`に戻る）ボタンは一旦なくなった。必要であれば別途検討する。
- 現状はGame 1のみ。別のゲームを追加する場合は、そのゲーム専用の起動画面・開始画面をこのアプリとは別に用意する想定（詳細は未定）。
