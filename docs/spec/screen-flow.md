# 画面構成・遷移フロー

## 画面一覧

| パス | 画面名 | 説明 |
| --- | --- | --- |
| `/` | スタート画面 | ロゴ表示、初回はユーザー名登録、Startボタンでメニューへ |
| `/menu` | ゲームメニュー画面 | 遊ぶゲームを選ぶ画面。共通通貨を右上に表示 |
| `/games/game1` | Game 1 開始画面 | 背景＋タイトルのフェード演出のあと「タップして開始する」でホームへ |
| `/games/game1/home` | Game 1 ホーム画面 | 「冒険する」「キャラクター」「バッグの中身」「ゲームを終了」の4ボタン |
| `/games/game1/character` | キャラクター確認画面 | [screens/character-view.md](./screens/character-view.md)参照 |
| `/games/game2` | Game 2 | 未実装（メニュー上は「Coming soon...」でタップ不可） |
| `/games/game3` | Game 3 | 未実装（メニュー上は「Coming soon...」でタップ不可） |

## 遷移フロー

```
/ (スタート画面)
  └─ Startボタン →  /menu (ゲームメニュー)
                        ├─ Game1タップ → /games/game1 (開始画面：背景/タイトルのフェード演出)
                        │                   └─ 演出後、画面タップ → /games/game1/home (ホーム画面)
                        │                                              ├─ 「冒険する」（未実装）
                        │                                              ├─ 「キャラクター」→ /games/game1/character
                        │                                              │                       └─ ✕ボタン → /games/game1/home に戻る
                        │                                              ├─ 「バッグの中身」（未実装）
                        │                                              └─ 「ゲームを終了」→ /menu
                        ├─ Game2（無効・Coming soon...）
                        └─ Game3（無効・Coming soon...）
```

## 現状の制約・未実装事項

- URLを直接叩けば `/menu` や `/games/game1` に、スタート画面を経由せずアクセスできる（ルートガードは未実装）。
- Game 2 / Game 3 のページ自体はまだ存在しない（メニュー上でリンク自体を無効化しているのでリンク切れにはならない）。
- Game 1ホーム画面の「冒険する」「バッグの中身」ボタンは見た目のみで、押しても何も起きない。
