# 戦闘ステージ

実装: [lib/battle-stages.ts](../../lib/battle-stages.ts)

## ID命名規則

`bs{ワールド2桁}-{ステージ2桁}`（`bs`はbattle stageのbs）。マリオの「1-1」「1-2」→「2-1」と同じ発想で、ワールドを跨いだら2桁目をリセットして1つ目の桁を上げる。

例: `bs01-01` → `bs01-02` → ... → `bs02-01`

## 1ステージが持つ情報

| 項目 | 内容 |
| --- | --- |
| `id` | 上記の命名規則のID |
| `backgroundId` | 使用する戦闘背景（[fields.md](./fields.md)のID。例: `f01`） |
| `enemyIds` | 1体目〜3体目に出す敵のID（[enemies.md](./enemies.md) / [roster.md](./roster.md)参照）を3要素の配列で指定。2体目・3体目は `null` にすると「敵なし」 |

ステータス（HP・攻撃力など）や出現率のようなバトル内容は、このファイルの対象外（決まり次第、別途正規化する）。

## 現状

サンプルとして `bs01-01`（背景`f01`、敵は1体目に`e01`のみ）だけを用意している。実際のステージ構成（どのステージにどの敵をどの並びで出すか）はこれから決めていく。まとめて渡してもらう場合は、この形式（`id` / `backgroundId` / `enemyIds`の3項目）に沿った一覧で問題ない。

## 画面での使われ方

[screens/battle.md](./screens/battle.md)を参照。仲間キャラの並びとは独立していて、戦闘ステージ側は「背景」と「敵の並び」だけを定義する。
