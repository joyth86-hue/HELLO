# スキルデータ

[共通UIボタン素材](./ui-buttons.md)の攻撃スキル・支援スキル画像（17枚）に対応するスキルの内容。名称・種別・対象・属性・CT・倍率などはユーザー確認済みの内容で確定している。ダメージ計算に関わる数値（`baseValue`・支援効果の量など）は仮値で、後からバランス調整として書き換えられる想定。

実装：
- [lib/skills-info.ts](../../lib/skills-info.ts)（`SKILL_BASE_INFO`＝全17件の一覧、`CHARACTER_SKILL_KIT`＝キャラごとに現在採用している4枠分のスキルID、`STARTER_SKILLS`＝初期解放済みの4スキル）
- [lib/skill-progression.ts](../../lib/skill-progression.ts)（スキルポイントによる解放・強化の計算）
- 戦闘画面（[battle-test.md](./screens/battle-test.md)）の行動ボタン・CT表示、キャラクター画面（[character-view.md](./screens/character-view.md)）のスキル解放・強化UIから参照している。

## キャラごとの現在のキット（4枠）

1キャラあたりのボタンは5枠（通常攻撃1＋スキル4）。キャラごとに使用スキルをちょうど4つに揃え、5枠すべてを埋めている。**枠2（各キャラの1つ目のスキル）が初期解放済みのスターター枠**（`STARTER_SKILLS`）。

## CT（クールタイム）

- CTは**ユニット自身の手番が何回回ってきたか**で数える（全員が1巡する「グローバルなターン」ではない）
- CT1＝「使用後、自分の次の手番を1回スキップしないと再使用できない」。通常攻撃のみCT0（毎回使用可）
- ステージ内の10連戦（S-1〜S-10）をまたいで持ち越し、**ステージ開始（S-1）時のみリセット**される（HPの持ち越しと同じ扱い）
- 実装：`app/games/game1/battle/page.tsx`の`BattleUnit.ownTurnCounter`（自分の手番カウンター）と`skillAvailableAtTurn`（スキルIDごとの「このカウンターを超えたら使用可」の閾値）

## スキルの解放・強化（スキルポイント）

- 各キャラの**枠2（スターター）は最初から解放済み**。それ以外の3枠は未解放（🔒アイコン表示）で、**スキルポイント**を消費して解放する
- 解放は**10ptで1段階**の固定コスト（装備の合成と同じ考え方）。解放した直後は+0
- **攻撃スキルのみ**、解放後さらに10ptずつ投入して強化できる（`baseValue`が＋1につき元の基礎値の5%増で伸びる、装備の合成と同じ式）。**支援・回復スキルは効果量が強化段階の影響を受けないため、解放後のさらなるポイント投入自体を行わない**（ユーザー確認済み：固定でいく方針に確定。スキル画面では「強化」ボタンの代わりに「解放済み」と表示するだけになる）
- スキルポイントは経験値ポイントとは別の資源。**ステージ「クリア」時のみ**固定量（`SKILL_POINTS_PER_STAGE_CLEAR`＝5pt）が加算される。全滅時の部分回収の対象外で、ステージが進んでも金額は変わらない点が経験値との違い（ユーザー確認済み：意図的な差別化）
- 解放・強化UIはキャラクター画面（[character-view.md](./screens/character-view.md)）の「スキル」ボトムシートから操作する

## スキル効果の種類

- **攻撃**：`baseValue`（強化分を反映）をキャラの攻撃力に加算してダメージ計算（[combat.md相当のダメージ式]）。対象は「敵単体」（ランダム1体）または「敵全体」。`hits`が2以上の場合は同じ対象に複数回ヒット（sk003は同じ敵に2回攻撃し、2回分を合計すると全スキル中最大火力になる設計）
- **支援**：発動した時点で生きている味方全体に、指定ステータス（攻撃力／防御力／会心率／属性耐性）へのバフを付与。効果は「バフを受けた側の自分の手番」基準で指定ターン数（現状3ターン）持続する。効果量は強化段階に関わらず固定（ユーザー確認済み）
- **回復**：発動した時点で最もHP割合が低い生存中の味方1体を、最大HPの一定割合（現状sk008のみ実装、20%固定）回復する。対象は自動選択のままで確定（プレイヤーが選ぶ形にはしない、ユーザー確認済み）。効果量は強化段階に関わらず固定（ユーザー確認済み）
- **妨害（skipNextTurn）**：sk012・sk016は攻撃と同時に、命中した敵の次の手番を1回封じる

属性相性倍率（`lib/combat.ts`の`getElementMultiplier`）は、[roster.md](./roster.md#属性の相性弱点耐性)の輪（水→炎→氷→草→岩→水）に基づき、隣接する属性同士のみ1.25倍／0.75倍、それ以外は1.0倍。通常攻撃は属性を持たないため常にこの1.0固定ルートを通る。
