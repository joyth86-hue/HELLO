# 共通UIボタン素材（framed_v1）

外部の画像制作用リポジトリ（`hirogames_images`）で作られた、文字なし・フレーム付きのドット絵ボタンセット。ホーム画面（マイページ的なメニュー導線）や戦闘画面の通常攻撃・スキルボタンに使う想定で作られたもので、[public/icons/buttons/](../../public/icons/buttons/)に取り込み済み。

- 戦闘画面（[battle-test.md](./screens/battle-test.md)）：通常攻撃・スキルボタンとして実装済み（[skills.md](./skills.md)参照）
- ホーム画面（[game1-home.md](./screens/game1-home.md)）：プレゼント・デイリーミッション・図鑑・設定の4つを配置済み（見た目のみ、機能は未実装）
- 残り（メール・クエスト一覧・パーティ確認・戦闘補助UI4種）は未配置

素材の出所・仕様：`hirogames_images/assets/ui/game_buttons/framed_v1/README.md`（引継ぎ元）。元データは同フォルダの`individual/`（33枚の個別PNG）。

## 共通仕様

- 512×512px PNG、RGB、不透明背景（透過ではない。背景込みでボタンとして完成している）
- 共通フレーム：濃紺の角丸正方形＋細いアイボリー外周＋控えめな金色の内周
- 絵柄：太めの暗色輪郭、少ない色数、硬いピクセルエッジ
- 文字・キャラクター名・数値は画像内に含まれていない（名称やクールダウン表示は実装側で重ねる前提）

## 収録内容（33枚）

| カテゴリ | 枚数 | 内容 |
| --- | --- | --- |
| 汎用UI | 8 | 戻る・デイリーミッション・プレゼント・メール・設定・クエスト一覧・パーティ確認・ガイド |
| 通常攻撃 | 4 | アカネ・コユキ・サユミ・カエデ、各1種類 |
| 攻撃スキル | 12 | アカネ3・コユキ3・サユミ3・カエデ3 |
| 支援スキル | 5 | アカネ1・コユキ1・サユミ1・カエデ2 |
| 戦闘補助UI | 4 | 一時停止・オート戦闘・戦闘速度変更・ターゲット選択 |

ファイル名・カテゴリ・キャラクター・和名の対応は、このアプリのリポジトリ外にある画像制作用リポジトリ（`hirogames_images/assets/ui/game_buttons/framed_v1/manifest.csv`）の内容をそのまま`public/icons/buttons/`のファイル名に反映している（例：`skill_akane_flame_slash.png`＝アカネの攻撃スキル「炎の斬撃」）。個別のスキル名一覧は本ドキュメントでは重複させず、上記manifest.csvを正とする。

- 残りの汎用UI（メール・クエスト一覧・パーティ確認）はまだどこにも配置していない
